# Builds Directory

Compiled native executables produced by `./scripts/build_all.sh` are placed here (`builds/calculator`, `builds/pomodoro`, `builds/devbox`, `builds/sysbench`, `builds/term_snake`, `builds/neon_breakout`, `builds/voxel_runner`).

Compiled binaries are ignored by Git (`builds/*`) and published as downloadable artifacts in the [GitHub Releases](../../releases) page.
